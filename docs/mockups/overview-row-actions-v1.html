Обзор: что можно сделать с источником

Сейчас в строке при наведении только ▶ и «⋯», а всё остальное спрятано в меню. Нужно: запустить, прочитать инструкцию (если есть), изменить, открыть оригинал и копию. И клик по самой строке должен что-то делать.

что значит «открыть» для каждого типа

ТипОткрыть оригиналОткрыть копию
Папка (Obsidian, Anki, настройки)папку источника в Finderсамую свежую копию в Finder. Если назначений несколько — выбор из списка. Копия в облаке в Finder не открывается: пункт виден, но неактивен, с подсказкой
Команда (GitHub, Bitwarden, Claude Code)нет оригинала на диске — кнопки нет
Ручной экспорт (Пароли, Google Photos)нет — кнопки нет
По шагам (Claude)нет — кнопки нет
АКнопки прямо в строке при наведении, клик по строке — «Изменить»
