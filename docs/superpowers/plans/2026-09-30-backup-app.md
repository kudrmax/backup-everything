# Backup Everything: приложение — план реализации

**Goal:** macOS-приложение поверх `BackupCore`: иконка в menu bar, окно с разделами «Обзор», «Источники», «Назначения», «История», фоновая работа, уведомления, автозапуск.

**Spec:** `docs/superpowers/specs/2026-09-30-backup-manager-design.md` (разделы 5.5–5.7, 7).

**Architecture:** пакет `App/` с исполняемым таргетом `BackupEverything` (SwiftUI) и зависимостью от `../BackupCore`. `AppModel` (`@MainActor @Observable`) — единственный посредник между экранами и ядром. `BackgroundDriver` превращает системные события (таймер до `nextWake`, пробуждение, монтирование тома, изменения в папках ручного экспорта) в вызовы `tick()`. Сборка `.app` — скриптом `scripts/build-app.sh`, без Xcode-проекта.

Формат: Макс делегировал технические решения и попросил сразу перейти к UI, поэтому план краткий, без кода в тексте. Логика покрывается тестами по TDD, экраны проверяются запуском приложения.

## Задачи

1. **Ядро: шаблоны в коде.** Встроенные шаблоны переезжают из ресурсов пакета в `BundledTemplates.swift`: так `.app` не зависит от ресурсного бандла SwiftPM. Поведение `installBundledTemplates` не меняется, существующие тесты остаются.
2. **Ядро: занятое место.** `DestinationStore.usedBytes()` для локальной папки и rclone (`rclone size --json`).
3. **Ядро: редактирование настроек.** `ConfigEditor`: создание источника с уникальным slug, сохранение и удаление источников и назначений (удаление назначения убирает его из источников), поиск пересекающихся масок ручного экспорта на одной папке.
4. **Каркас приложения.** `App/Package.swift`, точка входа, `AppModel`, пути данных, скрипт сборки `.app` с `Info.plist` (`LSUIElement`, описания доступа к папкам), защита от второго экземпляра.
5. **Фон.** `BackgroundDriver`, `FolderWatcher`, `Notifier`, `LoginItem`.
6. **Menu bar.** Иконка по статусу, список «требует внимания», «Запустить всё сейчас», «Открыть окно», автозапуск, «Выйти».
7. **Окно.** «Обзор», «Источники» (форма с шаблонами, превью хранения, предупреждение о пересечении масок), «Назначения» (доступность, занятое место, снапшоты, «Показать в Finder», список remote из rclone), «История».
8. **Проверка.** Сборка, запуск, прогон сценария «папка → локальное назначение» на настоящем приложении.
